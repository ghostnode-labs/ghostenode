# Fluffogotchi

The Tamagotchi from the GhostNode Furry Hub as a standalone offline game – hatch, feed, boop and play with your fluffy pet.

- Open `index.html` in any modern browser (Chrome, Edge, Firefox, Safari) – no install, no account, no server.
- Save games stay in this browser (localStorage). Use ⚙️ → *Save games* to export/import them as a file.
- Time runs for real: your pet gets hungry while the window is closed (holiday mode in the settings pauses that).

Built automatically from the website source (`tools/build-fluffogotchi.js`) – the game logic is the same as on ghostnode-labs.dev/furhub.php.
